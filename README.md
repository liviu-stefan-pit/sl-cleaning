# SL Cleaning

WPF tool for Windows that lists installed software and uninstalls what you select.

It runs PowerShell scripts to inventory programs as JSON, shows names and icons, filters the list, and uninstalls the checked rows. Logging sits next to the uninstall flow. The UI uses MVVM with CommunityToolkit.Mvvm.

Open `SL-Cleaning.sln` and run the WPF project on Windows. .NET 8.
